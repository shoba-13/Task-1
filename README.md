CodeAlpha C Programming Internship – Basic Calculator
Project Description
A menu-driven calculator written in C. It performs addition, subtraction,
multiplication, and division. It also checks invalid menu choices and prevents
division by zero.
Features
- Addition
- Subtraction
- Multiplication
- Division
- Decimal number support
- Division-by-zero handling
- Repeats until the user selects Exit
Requirements
- GCC compiler or any C compiler
- Windows, Linux, macOS, or an online C compiler
How to Run
Using GCC
Open a terminal in this folder and run:
gcc calculator.c -o calculator
On Windows:
calculator.exe
On Linux/macOS:
./calculator
You can also paste calculator.c into an online C compiler and click Run.
